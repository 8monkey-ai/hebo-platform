title: "Transcriptions"
description: "Transcribe audio into text"
---

You can transcribe audio with the same OpenAI-compatible `/audio/transcriptions` API across providers.

Common use cases include meeting notes, voice input, subtitles, and call analysis.

<CodeGroup>

```ts OpenAI SDK highlight={9-12}
import fs from "node:fs";
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.HEBO_API_KEY,
  baseURL: "https://gateway.hebo.ai/v1",
});

const { text } = await client.audio.transcriptions.create({
  model: "openai/gpt-transcribe",
  file: fs.createReadStream("meeting.mp3"),
});

console.log(text);
```

```bash Bash
curl https://gateway.hebo.ai/v1/audio/transcriptions \
  -H "Authorization: Bearer $HEBO_API_KEY" \
  -F model="openai/gpt-transcribe" \
  -F file="@meeting.mp3"
```

</CodeGroup>

The Gateway detects the audio format from the file extension or the MIME type.

## Base64 Input

You can also send the audio as base64 in a JSON body:

```bash Bash
curl https://gateway.hebo.ai/v1/audio/transcriptions \
  -H "Authorization: Bearer $HEBO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-transcribe",
    "input_audio": { "data": "<base64>", "format": "mp3" }
  }'
```

## Options

- `language` — the language of the audio (e.g. `en`).
- `prompt` — text that guides the style or the vocabulary of the transcript.
- `temperature` — a value from `0` to `1`.
- `response_format` — `json` (default) returns `text` and `usage`. `verbose_json` also returns `language` and `duration` when the model reports them. The timings depend on the model:
  - `openai/gpt-transcribe` returns no timings. The Gateway always requests `json` from this model.
  - `google/gemini-3.5-transcribe` and `xai/grok-voice-transcribe-2.0` return word timings in `words`. `segments` is always empty.
- `timestamp_granularities` — set to `["word"]` to get word timings from `google/gemini-3.5-transcribe`. `xai/grok-voice-transcribe-2.0` always returns word timings. In multipart forms, send this field as `timestamp_granularities[]`.

## Supported Models

- `openai/gpt-transcribe`
- `google/gemini-3.5-transcribe`
- `xai/grok-voice-transcribe-2.0`

<Info>
  Request bodies can be up to 35 MB. Base64 adds about 33% to the size of the audio. Streaming is
  not supported: `stream: true` returns a `400` error.
</Info>
