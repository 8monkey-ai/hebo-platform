---
title: "Models"
description: "List all models available on Hebo Gateway"
---

Simply call the `/models` endpoint:

```bash Bash
curl https://gateway.hebo.ai/v1/models
```

To get a single model, add its ID to the path:

```bash Bash
curl https://gateway.hebo.ai/v1/models/openai/gpt-oss-20b
```

<Info>These endpoints do not require authentication</Info>
