Apps such as Claude Desktop and Codex connect to Hebo Gateway through a model alias from your Hebo agent. Requests to an alias show in the agent's **Traces**.

## Set Up a Model Alias

1. In the [Hebo Console](https://console.hebo.ai), open **Providers** and configure the credentials of your provider (for example Anthropic, OpenAI, or Amazon Bedrock).
2. Open **Models**. Add a model or edit one and select its **Type**. Then in **Advanced options**, select **Bring Your Own Provider** and your provider.
3. Copy the **Alias path**, for example `my-first-agent/main/default`.
4. Open **API Keys** and create a key.

<Info>
  If a request fails with `BYOK_REQUIRED`, the alias has no provider with credentials. Do steps 1
  and 2 again.
</Info>
